How the quiz library works
  • Question types: multiple choice (2–4 answers), true / false, number (with an optional ± tolerance) and gap fill (students type a word; you list every accepted answer, separated by |).
  • Excel import: download the template, fill one question per row, save, then use Import file. CSV files with commas or semicolons work too.
  • Quizzes are saved in this browser on this computer. Use Back up all quizzes to keep a copy or move them to another computer.
  • Students never receive the correct answers in advance: each phone only gets the current question.
